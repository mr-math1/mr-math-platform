MR. MATH — النسخة الأولية
========================

تشغيل الموقع:
1) فك ضغط الملف.
2) افتح index.html في متصفح حديث.
3) لا يحتاج الموقع إلى تثبيت أو خادم لتجربة النسخة الأولية.

النشر المجاني عبر GitHub Pages:
1) أنشئ حسابًا في https://github.com
2) أنشئ مستودعًا جديدًا (New repository)، واجعله Public.
3) ارفع الملفات الثلاثة: index.html و style.css و app.js.
4) افتح Settings ثم Pages.
5) من Build and deployment اختر Deploy from a branch.
6) اختر main ثم /(root) واضغط Save.
7) انتظر ظهور رابط الموقع في صفحة Pages.

ملاحظات:
- هذه نسخة واجهة أولية تعمل على الهاتف والكمبيوتر.
- أسئلة التدريب الحالية أمثلة توضيحية وليست بنك أسئلة معتمدًا للمنهج.
- النتائج محفوظة أثناء جلسة الاستخدام فقط؛ لوحة متصدرين فعلية وحسابات الطلاب ولوحة تحكم المعلم تحتاج إلى ربط قاعدة بيانات وخدمة خلفية.
- يمكن تعديل الأسئلة في مصفوفة questions داخل app.js.
